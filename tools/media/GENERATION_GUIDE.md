# Хромакей: вырезание фона

Здесь только один пайплайн — вырезание фона на хромакее. Остальное из того, что
было перенесено из narthex (квоты, промпт-шаблоны, озвучка, лицензии), удалено:
для Synapse это не нужно. Инструмент — `tools/media/cutout-chromakey.py`
(обёртка `cutout-chromakey` после `tools/media/setup.sh`).

## Почему так

Генераторы изображений (включая ИИ) **не делают реальный альфа-канал** — промпт
«transparent background» даёт псевдо-шахматку серыми квадратиками. Единственный
рабочий процесс: генерация на однородном хромакее, потом вырезание программно.

## Пайплайн

1. **Генерировать на сплошном ядовито-зелёном фоне `#00FF00`:**
   `solid flat acid green background #00FF00, no floor, no shadows, no ground, no gradients`

2. **Вырезать:**
   ```bash
   cutout-chromakey input.png output.png --mode auto --crop
   ```
   * `--mode auto` (по умолчанию): строгий ключ + внутренние замкнутые полости
     (окна/отверстия) + despill ореола. `--crop` — обрезка по tight bbox.
   * **Бирюзу/циан не вырезает ни в одном режиме**: в одной из ранних версий ключ
     был слишком мягким, бирюзовые детали (вены, кольца) вырезались, и иконки
     получались с дырами. Только если фон снят в бирюзе — `--allow-cyan`.
   * Зелёный, запертый внутри фигуры (окна, отверстия, буквы A/B/D/O/P/R):
     `--mode color` (глобально) или `--mode points --points "X,Y"` (точечно),
     или ImageMagick: `convert input.png -fuzz 25% -transparent '#00FF00' output.png`.
     Зелёного в финальном ассете не должно оставаться ни при каких обстоятельствах.

3. **Обязательно посмотреть результат глазами** (read_file на картинке / контактный лист).

4. **Испорченные иконки лечатся, а не перерисовываются:**
   ```bash
   cutout-chromakey --heal сломанная.png починенная.png
   ```
   Цвет под прозрачностью сохраняется, поэтому восстановление точное. Лечатся только
   пиксели внутри фигуры; внешний фон и легальные зелёные окна не трогаются.

## Установка

```bash
tools/media/setup.sh --check     # venv /tmp/synapse-media (Pillow) + самотест
export PATH="/tmp/synapse-media/bin:$PATH"
cutout-chromakey in.png out.png --mode auto --crop
```

## Что перенесено и что пофиксено

Источник: `Creative36711/narthex`, `scripts/cutout-chromakey.py` (c842670). Отличия этой
копии от оригинала:

* `--mode flood` реально вырезает внешний фон (в оригинале не делал ничего);
* добавлен `--no-despill` (в оригинале despill нельзя было выключить).

Тесты для пайплайна: `tools/media/test_media_tools.py` (запускается через
`setup.sh --check`).
