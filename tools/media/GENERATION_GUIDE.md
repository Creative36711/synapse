# Генерация медиа: изображения и озвучка

Русская инструкция для агентов (и человеков), которые делают медиа для Synapse.
Перенесена и адаптирована из `Creative36711/narthex` (`docs/ai-campaign-guide.md`,
`docs/agents/generation-quotas.md`, `docs/decisions/NAR-4.1.md`, c842670) — там эти правила
отработали на реальной кампании (462 изображения, 372 клипа озвучки).

## 1. Что и зачем

Медиа — это ассеты игры: спрайты, портреты, фоны, иконки (изображения) и реплики
(озвучка). Игра продаётся картинкой и звуком. Векторный силуэт — макет; ИИ-кадр — игра.

**Квота Arena (свойство среды, не поломка):** за один ход доступно **не больше
10 изображений и 10 аудиоклипов**. Квота обнуляется на следующий ход. Если один вызов
вернул несколько вариантов, считай консервативно: это несколько изображений.

Планируй медиа **ходами**, а не файлами. Единица планирования — **медиаблок**:
не больше 10 изображений и 10 клипов озвучки = одна задача = один ход.

1. **Генерация не смешивается с кодом.** Медиа-задача содержит только медиа;
   кодовая задача медиа не генерирует.
2. **Один ход — один блок.** «Добью остаток в этом же ходу» — это 11-й вызов,
   который провалится или молча обрежет партию.
3. **Планируй по приоритетам, а не по списку:** сначала каркас (титул, первые фоны,
   нейтральные портреты, карта), потом атмосфера и бой, потом сюжетные кадры,
   в последнюю очередь иконки и вторичные детали. Порядок — по видимости игроком.
4. **Озвучка — вторым проходом**, после заморозки текста реплик. Озвучивать меняющийся
   текст — двойная работа.
5. **Леджер — единственный источник правды.** `.generation-plan.md` в корне медиа-проекта:
   `файл | назначение | размер | промпт | партия | статус | ход`. Статусы: план, готово,
   брак, отложено. Расхождение леджера и файлов — дефект.

## 2. Инструменты в этом репозитории

```bash
tools/media/setup.sh --check        # venv /tmp/synapse-media: Pillow + ffmpeg + тесты
export PATH="/tmp/synapse-media/bin:$PATH"
# теперь доступны: cutout-chromakey, media-check, ffmpeg
```

* `cutout-chromakey` — вырезание фона `#00FF00` (порог строгий: бирюзу не ест) + лечилка `--heal`.
* `media-check <dir|files>` — приёмка: сигнатура vs расширение, остаток хромакея (>0.5 %
  непрозрачного зелёного — брак), вес (>4 МБ — фото, >8 МБ — аудио), дубликаты по sha256.
* `ffmpeg` — статика 7.0: mp3/ogg/opus/wav, loudnorm, silenceremove.

## 3. Пайплайн изображения: хромакей

Генераторы **не делают реальный альфа-канал** — «transparent background» даёт псевдо-шахматку.
Единственный рабочий процесс:

1. **Генерировать на сплошном ядовито-зелёном фоне `#00FF00`**
   (в промпте: `solid flat acid green background #00FF00, no floor, no shadows, no ground, no gradients`).
2. **Вырезать программно:**
   ```bash
   cutout-chromakey input.png output.png --mode auto --crop
   ```
   * `--mode auto` (default): строгий ключ + внутренние замкнутые полости (окна/отверстия)
     + despill ореола. `--crop` — обрезка по tight bbox.
   * Бирюзу/циан **не вырезает ни в одном режиме** (урок «Каркас»: старая версия вырезала
     бирюзовые детали, и иконки получили дыры). Только если фон снят в бирюзе — `--allow-cyan`.
   * Зелёный внутри фигуры (запертая полость) — `--mode color` (глобально) или
     `--mode points --points "X,Y"` (точечно) или ImageMagick `convert in.png -fuzz 25% -transparent '#00FF00' out.png`.
     Зелёный ни при каких обстоятельствах не должен оставаться в финальном ассете.
3. **ОБЯЗАТЕЛЬНО посмотреть результат глазами** (read_file на картинке / контактный лист).
4. **Испорченные иконки лечатся, а не перерисовываются:**
   ```bash
   cutout-chromakey --heal сломанная.png починенная.png
   ```
   Цвет под прозрачностью сохраняется, поэтому восстановление точное. Лечатся только
   пиксели внутри фигуры; внешний фон и легальные зелёные окна не трогаются.
5. **Приёмка командой:** `media-check <директория>` — 0 failures.

### Промпт-шаблоны

* **Спрайт персонажа:** `full-body standing character, eye-level front view, feet grounded
  at the bottom frame, concept art, isolated on solid chromatic green background #00FF00,
  no floor, no shadows --ar 9:16`
* **Портрет в диалоге:** `close-up bust portrait, head and shoulders, expressive emotion,
  face focused in upper frame, cinematic lighting, detailed face --ar 1:1`
* **Фигурка боя (топдаун):** `top-down tabletop miniature token, high-angle downward
  perspective 75 degrees bird-eye view, top of head, shoulders and weapon visible,
  facing upward north, isolated on solid chromatic green background #00FF00, no shadow --ar 1:1`
* **Фон сцены:** `wide panoramic fantasy interior/landscape, matte painting, atmospheric
  lighting, eye-level horizon, empty walkable floor in foreground, 16:9 --ar 16:9`
* **Иконка предмета:** `isolated game item icon, clean fantasy artifact, centered
  composition, sharp silhouette, high contrast, isolated on solid chromatic green
  background #00FF00 --ar 1:1`

### Анимация (Godot)

Движок анимирует любой спрайт двумя способами:
* **Покадровая** — `frames: [res://assets/x_1.png, res://assets/x_2.png, ...], fps: 6, loop: true`;
* **Спрайт-лист N×M** — `sheet: res://assets/x.png, cols: 4, rows: 2, fps: 8, loop: true`
  (2D: `AnimatedSprite2D` + `SpriteFrames`; 3D: `Sprite3D`/код по смене кадров).
Генерируй анимацию как кадры одного стиля (один промпт с парой «стояние/действие»),
не смешивая стили в одном объекте.

## 4. Озвучка

Голос — русская ИИ-озвучка. Музыка и звуки эффектов — настоящие записи (CC0/роялти-фри),
синтез только для черновиков.

1. **Голос на персонажа на всю кампанию.** Зарегистрируй голосовую роль (`add_voice` —
   два кандидата на прослушивание, пользователь выбирает), затем синтезируем реплики
   (`generate_speech`, до ~1500 символов на клип). Рассказчик — отдельный голос.
2. **Квота:** ≤10 клипов озвучки за ход. Дели реплики на медиаблоки (как изображения).
3. **Упрощённый порядок:** сначала dialogue-файлы с текстом реплик (замораживаются),
   потом озвучка партиями. Не озвучивайте текст, который ещё меняется.
4. **ffmpeg для обработки** (при необходимости):
   ```bash
   ffmpeg -i raw.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 loud.mp3
   ffmpeg -i raw.wav -af silenceremove=start_periods=1:start_duration=0.1 out.ogg
   ```
   Форматы в игре: mp3/ogg/wav. Вес — до 8 МБ на файл.

## 5. Лицензии (практическое правило, не юридический экзамен)

Разрешено: CC0, CC-BY, CC-BY-SA, OFL (шрифты), royalty-free библиотеки, купленные лицензии.
Достаточно одной строки на источник в атрибуции: откуда взято и под какой лицензией.
Запрещено: пиратские копии, рипы из игр/фильмов, «нашёл в интернете без источника».

## 6. Что запрещено

- Генерировать медиа для dev-полигонов (лишние файлы ломают лёгкость фикстуры).
- Обходить квоту вторыми сессиями или «на всякий случай» повторными вызовами.
- Молча заменять отсутствующий ассет заглушкой и писать, что он есть.
- Пустые сцены вместо картинок: в витринном продукте растровый файл — требование,
  а не стиль. «Потом подставим» — дефект.
